# AI Coding Test · 交互式 HTML 演示

打开 `index.html` 即可播放。建议使用 Chrome、Safari 或 Edge，并进入浏览器全屏模式获得最佳效果。

操作方式：

- 首页点击「开启」。
- 其余页面点击底部圆形箭头，或使用鼠标滚轮 / 触控板上下滑动。
- 也支持方向键、Page Up / Page Down、空格键、Home 和 End。
- 最后一页的箭头会回到首页。

页面使用 1600 × 900 的固定设计舞台，并自动等比缩放到当前窗口；换页只发生在当前可视区域，不会触发页面滚动。封面「开启」会先带动底部深灰幕布下移，再进入下一页；各页主要块面会按顺序入场。

动效使用项目内置的 GSAP 时间轴：封面标题与手机模型带轻微倾斜反馈，底部纸张和「开启」按钮均支持 hover，页面内容按阅读顺序错峰入场。系统开启“减少动态效果”时会自动切换为轻量淡入。

所有 Figma 图片、SVG、封面标题整图与 GSAP 运行文件均已保存在 `assets/`，无需联网。
